# Lesson 8 Homework: Final Readiness Checklist

**Use:** During final review before the exam, if proceeding

## Checklist

- Confirm the appointment, time zone, exam language, identity requirements, and testing setup using the official exam-provider instructions.
- Recheck the current GH-100 exam details on the [certification page](https://learn.microsoft.com/en-us/credentials/certifications/github-administration/).
- Review only the two priority objectives selected in class. Avoid a last-minute broad cram.
- Get adequate rest and prepare the testing environment.

If the exam is not booked or the learner is not ready, use the readiness note to choose a later date. The lesson completion checks and practice assessment do not guarantee an exam outcome.
