# Lesson 5 Homework: Actions Policy Review

**Suggested preparation for:** Lesson 6

## Study

- Review the Actions objectives in the [current GH-100 study guide](https://aka.ms/GH100-StudyGuide).
- Complete or review [Manage GitHub Actions](https://learn.microsoft.com/en-us/training/modules/manage-github-actions-enterprise/).
- Focus on policy, reusable workflows/components, runner options, and encrypted-secret scope.

## Practice

1. Open the [lesson guide](lesson-guide.md) and reuse the supplied static YAML. Do not install or run it.
2. Revisit Step 1's job table. Explain the tasks before naming permissions.
3. Check Step 2's change table for restrictive token access, allowed action sources, and reviewed version references.
4. Check Step 3's secret map and the separate same-repository/fork cases. Record the settings or documentation still needed to confirm behavior.
5. Review Step 4's expected allowed/denied tests. Keep actual results as "not run"; do not add secrets or execute the example.

## Retrieval Practice

On three different days, explain why token permissions are scoped to the job's task and how fork behavior changes the review.

## Bring to Class

- The governance review and test plan.
- One disputed policy choice and the evidence you would use to resolve it.
