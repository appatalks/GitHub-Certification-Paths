## Certification Resources

This section collects study notes, official references, and preparation links for
the GitHub certification paths tracked in this repository.

Each guide follows the same rhythm:

1. **Start here** with the official certification page and study guide.
2. **Learn the domains** using Microsoft Learn and GitHub Docs.
3. **Run a mission** so the concepts become something you can explain and use.
4. **Check yourself** before attempting the official practice assessment.

Use official Microsoft Learn and GitHub links as the authority for current exam
objectives, policies, and registration details. These notes are personal study
aids, not official GitHub or Microsoft training materials. Product names,
features, and exam objectives change, so check the source pages before exam day.
